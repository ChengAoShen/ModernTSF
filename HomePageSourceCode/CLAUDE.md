# Diaugeia deck templates

Two template families live in this repo. Both ship a **light** and a **dark**
variant and share one palette + type system, mirrored from the diaugeia.ai
website (`app/globals.css`).

| Need | Use | Where |
|------|-----|-------|
| Text-first, version-controllable, code-heavy slides | **Marp** | `MarpTemplate` |
| Editable PowerPoint to hand to non-technical people | **PowerPoint** | `PPT_Template` |

## Brand tokens (do not improvise colors)

| Token | Light | Dark |
|-------|-------|------|
| paper / page bg | `#FBFAF7` | `#0E0E0D` |
| graphite panel  | `#1A1A18` | `#211F1B` |
| alt surface     | `#F3F1EA` | `#161614` |
| primary ink     | `#1A1A18` | `#ECEAE3` |
| muted text      | `#6C6A61` | `#9C9A90` |
| **gold accent** | `#8C6F24` | `#D6B25E` |
| border          | `#D6D2C4` | `#2A2926` |

Type: **Times New Roman** (serif display, headings) + **Arial** (sans body) +
**Fira Code / Consolas** (code). The brand cue is a soft gold **light-beam
glow** on the background; the literal logo (`LOGO/diaugeia.png`) is itself a
glow, so use it sparingly — one or two identity moments per deck.

## Marp

Themes: `MarpTemplate/themes/diaugeia_{light,dark}.scss`
(both `@import 'diaugeia_base'`, which holds all layout). Example deck:
`MarpTemplate/template/Diaugeia_Template.md`.

**Author a deck** — copy the example and set the front-matter:

```markdown
---
marp: true
size: 16:9
theme: diaugeia_light   # ← or diaugeia_dark; nothing else changes
paginate: true
footer: Diaugeia · Transparent infrastructure for AI research
---
```

**Per-slide layout** is chosen with `<!-- _class: ... -->`. Available classes:
`cover_e` (title), `toc_b` (agenda), `trans` (section divider), `navbar`
(content slide with a top section bar), `lastpage` (closing), and the grid
helpers `cols-2`, `cols-2-64`, `cols-2-37`, `cols-3`, `rows-2`, `pin-3`
(use `<div class=ldiv>/<rdiv>/<limg>/<rimg>` inside). Also `largetext`,
`smalltext`, `footnote`, `fixedtitleB`, `bq-*`.

**Render.** The Marp for VS Code extension reads the `.scss` directly (it has
built-in sass) — just open the file and Export. For the CLI, the `.scss`
`@import` is not resolved, so flatten first:

```bash
cd MarpTemplate
# build a self-contained css (base + palette), then render
for v in light dark; do
  { echo "/* @theme diaugeia_$v */";
    grep -vE "@theme diaugeia_base|@charset" themes/diaugeia_base.scss;
    grep -vE "@import 'diaugeia_base'|@theme diaugeia" themes/diaugeia_$v.scss;
  } > /tmp/diaugeia_$v.css
done
npx -y @marp-team/marp-cli@latest --allow-local-files \
  --theme /tmp/diaugeia_light.css template/Diaugeia_Template.md -o deck.html
```

(`--allow-local-files` is needed for the logo to load in CLI exports.)

## PowerPoint

Generated by `PPT_Template/build_templates.py` (python-pptx + Pillow).
Outputs `Diaugeia_Light.pptx`, `Diaugeia_Dark.pptx`, and derived art in
`assets/`: `logo_tile.png` (rounded dark logo tile) and `glow_{light,dark}.png`
(the soft gold radial bloom).

The decks are **glow-led, not logo-led**: the gold bloom (the website's
`GoldGlow`, baked to PNG by `make_glow`) is the recurring ambient on every
slide, and the literal logo appears only twice — a small tile on the cover and
on the closing. Echo the beam with `glow(...)`, don't paste the logo.

**Rebuild / edit:**

```bash
cd PPT_Template
pip3 install python-pptx Pillow      # once
python3 build_templates.py
```

The script is the source of truth — to change content or add a slide, edit the
`build()` function and the `slide_*` helpers, then re-run. Both decks come from
the same code with only the `LIGHT` / `DARK` palette dict swapped, so never
hard-code a color; read it from `pal[...]`. Slide builders available:
`slide_cover`, `slide_agenda`, `slide_section`, `slide_content`,
`slide_two_col`, `slide_quote`, `slide_closing`.

**Preview a .pptx as images** (verify before handing off):

```bash
soffice --headless --convert-to pdf --outdir /tmp/r Diaugeia_Light.pptx
pdftoppm -png -r 90 /tmp/r/Diaugeia_Light.pdf /tmp/r/L   # needs poppler
```

(`brew install --cask libreoffice` for `soffice`; `brew install poppler` for
`pdftoppm`.)

## Conventions

- Light & dark must stay in lock-step: any structural change goes into the
  shared layer (`diaugeia_base.scss` for Marp; the `slide_*` helpers for PPT),
  never into one variant only.
- Keep the gold accent **single and sparing** — it marks headings, list
  markers, rules, and the active nav item; body text stays graphite/ivory.
- The logo IS a glow, so don't over-use it: prefer the soft gold radial bloom
  (Marp `--glow`; PPT `glow(...)`) as the recurring brand cue, and reserve the
  literal logo for one or two identity moments (cover, closing).
