--------------------------------------------------------------------------------
筛选系统
--------------------------------------------------------------------------------

主类别 (2选1):
  ○ Common Static Dataset (通用静态数据集)
  ○ Real-Time Dataset (实时数据集)

子类别 (3列):
  Common Static:
    📈 Time Series | 🗺️ Spatial Temporal | 🔗 Covariate

  Real-Time:
    💰 Stock | 🚗 Traffic | 🌫️ Air Quality

数据集筛选 (8个):
  ☑ ETTh1    ☑ ETTh2    ☑ ETTm1    ☑ ETTm2
  ☑ Traffic  ☑ Solar    ☑ Electricity  ☑ Weather

Metrics (3个):
  ☑ MSE  - Mean Squared Error
  ☑ MAE  - Mean Absolute Error
  ☑ Runs - Number of runs

Display (6个):
  ☑ Show medals
  ☑ Performance bars
  ☑ Highlight top 3
  ☑ Compact mode
  ☑ Submission IDs
  ☑ Color by rank

Options (3个):
  • Table - 完整表格
  • Compact - 紧凑卡片
  • Detailed - 可展开详情

--------------------------------------------------------------------------------
使用指南
--------------------------------------------------------------------------------

1. 选择主类别
   点击 "Common Static Dataset" 或 "Real-Time Dataset"

2. 选择子类别
   点击三列中的任意一个 (Time Series / Stock / etc.)

3. 导航数据集
   使用 Previous / Next 按钮在数据集间切换

4. 筛选数据集
   使用搜索框或取消勾选不需要的类别

5. 自定义显示
   调整 Display / Metrics / Options 选项

6. 查看结果
   当前数据集的所有模型显示在下方表格中
