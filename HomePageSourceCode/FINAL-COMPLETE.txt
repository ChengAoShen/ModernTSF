完整功能列表
--------------------------------------------------------------------------------

✅ 1. 两层分类体系
   • Common Static Dataset (通用静态数据集)
   • Real-Time Dataset (实时数据集)

✅ 2. 三列子类别布局
   Common Static:
     - Time Series (时间序列) 📈

   Real-Time:
     - Stock (股票) 💰

✅ 3. 8个核心数据集筛选

   输入数据集名称即时筛选

   ☑ Color by rank - 按排名着色

✅ 8. Options 视图模式 (3种)
   • Table - 完整表格

✅ 9. 完整的中英文国际化

使用指南
--------------------------------------------------------------------------------

访问排行榜:
  1. 打开 http://localhost:3000/tseval/
  2. 右上角可以切换中英文

浏览数据:
  1. 选择主类别（Common Static / Real-Time）
  2. 选择子类别（Time Series / Stock 等）
  3. 使用 Previous/Next 按钮切换数据集
  4. 当前数据集的所有模型显示在表格中

筛选数据:
  1. 使用搜索框快速定位数据集
  2. 取消勾选不需要的数据集类别
  3. 调整 Display / Metrics / Options 选项

--------------------------------------------------------------------------------
数据格式
--------------------------------------------------------------------------------

leaderboard.json 结构:
  {
    "schema_version": "1.0",
    "n_submissions": 150,
    "tracks": {
      "time_series": {
        "datasets": {
          "ETTh1": {
            "horizons": {
              "96": [
                {
                  "model": "DLinear",
                  "mse": 0.375,
                  "mae": 0.398,
                  "n_runs": 3,
                  "rank": 1
                }
              ]
            }
          }
        }
      }
    }
  }

Track 名称:
  • time_series - 时间序列
  • spatiotemporal - 时空
  • covariate - 协变量
  • stock - 股票
  • traffic_rt - 交通
  • air_quality - 空气质量
