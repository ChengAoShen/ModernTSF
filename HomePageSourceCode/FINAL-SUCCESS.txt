技术细节
--------------------------------------------------------------------------------

### Track 命名规范

JSON 中必须使用以下 track 名称：

Common Static Dataset:
  - time_series      (Time Series)
  - spatiotemporal   (Spatial Temporal)
  - covariate        (Covariate)

Real-Time Dataset:
  - stock            (Stock)
  - traffic_rt       (Traffic - 注意后缀 _rt)
  - air_quality      (Air Quality)

### 数据结构示例

{
  "tracks": {
    "time_series": {
      "datasets": {
        "ETTh1": {
          "horizons": {
            "96": [
              {
                "model": "DLinear",
                "mse": 0.375,
                "mae": 0.398,
                "n_runs": 3,
                "submission_ids": ["..."],
                "rank": 1
              }
            ]
          }
        }
      }
    }
  }
}
