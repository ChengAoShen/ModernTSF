使用指南
--------------------------------------------------------------------------------

### 基础操作

1. 选择主类别
   - 点击 "Common Static Dataset" 或 "Real-Time Dataset"

2. 选择子类别
   - Common Static: Time Series / Spatial Temporal / Covariate
   - Real-Time: Stock / Traffic / Air Quality

3. 切换数据集
   - 点击 [Next →] 查看下一个数据集
   - 点击 [← Previous] 返回上一个

4. 筛选数据集
   - 使用搜索框快速定位
   - 勾选/取消8个核心数据集

5. 自定义显示
   - Display: 控制视觉效果
   - Metrics: 选择显示哪些指标
   - Options: 切换视图模式

### Metrics 使用示例

场景 1: 只看 MSE 排名
  ☑ MSE
  ☐ MAE  ← 取消
  ☐ Runs ← 取消
  结果：表格只显示 Model 和 MSE

场景 2: 对比 MSE 和 MAE
  ☑ MSE
  ☑ MAE
  ☐ Runs
  结果：同时显示两个误差指标

场景 3: 查看运行统计
  ☐ MSE
  ☐ MAE
  ☑ Runs
  结果：专注于实验次数
