--------------------------------------------------------------------------------
技术实现
--------------------------------------------------------------------------------

字典文件: lib/dictionaries.ts

结构:
  interface Dictionary {
    tseval: {
      title: string;
      categories: {...};
      filters: {...};
      datasets: {...};
      datasetDescriptions: {...};
      displayOptions: {...};
      metricsOptions: {...};
      viewModes: {...};
      navigation: {...};
      status: {...};
    };
  }

使用方式:
  const copy = dict.tseval;
  <button>{copy.navigation.previous}</button>

专有名词处理:
  • Track 名称: Time Series, Spatiotemporal 等保持英文
  • 数据集名称: ETTh1, ETTh2 等保持英文
  • 技术术语: MSE, MAE 保持英文缩写

--------------------------------------------------------------------------------
添加新翻译
--------------------------------------------------------------------------------

1. 在 lib/dictionaries.ts 的 TypeScript 接口中添加字段
2. 在 English (en) 字典中添加英文文本
3. 在 Chinese (zh) 字典中添加中文文本
4. 在组件中使用 copy.xxx 引用

示例:

// 1. Interface
tseval: {
  newField: string;
}

// 2. English
tseval: {
  newField: "New Text",
}

// 3. Chinese
tseval: {
  newField: "新文本",
}

// 4. Component
<div>{copy.newField}</div>
