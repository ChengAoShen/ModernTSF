✅ 模型搜索和完整度量指标已添加

🎊 新增功能:

1. ✅ 模型搜索功能
   • 独立的搜索框 "Search models"
   • 模糊搜索支持
   • 实时过滤匹配的模型
   • 默认显示全部，输入后只显示匹配项

2. ✅ 输入输出信息
   • Input: 60 (一个月的数据)
   • Output: 5 (预测5天)
   • 显示在数据集标题旁边

3. ✅ 完整的度量指标显示
   • MSE - 均方误差
   • MAE - 平均绝对误差
   • RMSE - 均方根误差
   • Corr - 相关系数
   • Fit Time - 训练时间
   • Inference Time - 推理时间
   • Runs - 运行次数

4. ✅ 所有指标可排序
   • 点击列标题排序
   • 支持升序/降序

--------------------------------------------------------------------------------
使用示例
--------------------------------------------------------------------------------

模型搜索:
  1. 在 "Search models" 框输入 "DLinear"
  2. 表格只显示名称包含 "DLinear" 的模型
  3. 清空搜索框恢复显示全部模型

模糊搜索示例:
  • 输入 "lstm" → 显示 LSTM, BiLSTM 等
  • 输入 "trans" → 显示 Transformer, iTransformer, Crossformer 等
  • 输入 "gnn" → 显示 CrossGNN, MTGNN, DSTAGNN 等

度量指标:
  • 在 Metrics 区域勾选/取消勾选来显示/隐藏列
  • 点击列标题进行排序
  • 默认按 MSE 排序
