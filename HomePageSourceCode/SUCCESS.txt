功能验证清单
================================================================================

在浏览器中打开 http://localhost:3000/tseval/ 并测试以下功能：

□ 1. 赛道切换
   - 点击顶部的 "Time Series", "Spatiotemporal", "Covariate" 标签
   - 每个赛道应显示不同的数据集

□ 2. 筛选面板
   - 找到 "Filters & Options" 面板
   - 应该看到以下部分：
     ✓ 搜索框 (Search datasets)
     ✓ 5个类别复选框 (Static/Stock/Traffic/Air Quality/Other)
     ✓ 6个显示选项复选框
     ✓ 3个视图模式按钮

□ 3. 数据集类别筛选
   - 取消勾选 "Static Datasets" → ETTh1, ETTh2 等应该隐藏
   - 取消勾选 "Traffic" → METR-LA, PEMS 等应该隐藏
   - 只保留 "Air Quality" → 仅显示空气质量数据集

□ 4. 搜索功能
   - 在搜索框输入 "ETT" → 应只显示 ETT 系列数据集
   - 输入 "METR" → 应显示交通数据集
   - 清空搜索 → 恢复所有数据集

□ 5. 显示选项
   - 取消勾选 "Show medals" → 奖牌图标变为数字
   - 取消勾选 "Performance bars" → 指标下方的条形图消失
   - 勾选 "Highlight top 3" → 前三名应有强调背景色
   - 勾选 "Compact mode" → 行间距变小

□ 6. 视图模式
   - 点击 "Compact" → 切换到卡片布局
   - 点击 "Detailed" → 表格带有 "Details" 按钮
   - 点击 "Table" → 回到标准表格视图

□ 7. 排序功能
   - 点击 "Model" 列标题 → 按字母顺序排序
   - 点击 "MSE" 列标题 → 按误差排序（↑ 或 ↓）
   - 再次点击 → 反转排序方向

□ 8. 数据集卡片
   - 每个数据集应有彩色类别徽章
     • Static → 蓝色
     • Stock → 绿色
     • Traffic → 紫色
     • Air Quality → 橙色
   - 点击不同的 "pred 96", "pred 192" 等 → 切换预测步长

□ 9. 响应式设计
   - 调整浏览器窗口大小
   - 筛选面板应自适应布局
   - 表格在窄视口下应可横向滚动

□ 10. 重置功能
   - 应用多个筛选后
   - 点击 "Reset all" 按钮
   - 所有筛选应恢复到默认状态

================================================================================
如果遇到问题
================================================================================

问题1: 页面显示 404
解决: 确保访问 http://localhost:3000/tseval/ (末尾有斜杠)

问题2: 页面空白或加载失败
解决: 
  1. 检查浏览器控制台是否有 JavaScript 错误
  2. 查看终端中的服务器日志
  3. 尝试刷新页面 (Cmd+R 或 Ctrl+R)

问题3: 样式不正确
解决:
  1. 检查 Tailwind CSS 是否正确加载
  2. 清除浏览器缓存并硬刷新 (Cmd+Shift+R 或 Ctrl+Shift+R)

问题4: 筛选不工作
解决:
  1. 打开浏览器开发者工具 (F12)
  2. 查看 Console 标签是否有错误
  3. 检查 leaderboard.json 数据格式是否正确
