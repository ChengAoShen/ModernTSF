快速开始
--------------------------------------------------------------------------------

1. 启动开发服务器:
   cd /Users/mjm/ModernTSF/HomePageSourceCode
   npm install
   npm run dev

2. 访问页面:
   http://localhost:3000/tseval

3. 使用示例数据 (可选):
   cp content/tseval/leaderboard-sample.json content/tseval/leaderboard.json
   npm run dev

4. 部署:
   npm run build
   npm run deploy
