# 模型与方法

ModernTSF 通过单一、平铺的公开目录提供 178 个模型和方法条目。用户侧不设置架构族分类；preset 只负责配置运行，不会创建额外条目。

实现来源只声明为 `upstream` 或 `rewrite`；可执行审计与数值 parity 门禁负责判断该声明是否达到发布要求。
